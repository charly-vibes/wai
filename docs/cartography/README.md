# Codebase Cartography — wai

Index of all cartography reports. **Open [`index.html`](index.html) in a browser** — the directory is self-contained and works offline via `file://` (diagrams render via the vendored `assets/mermaid.min.js`; no server, CDN, or build step needed).

- HTML pages (`cartography-*.html`) — derived, regenerable shareable view; regenerated by re-running the codebase-cartography skill (no build pipeline by design)
- Markdown files (`cartography-*.md`) — **artifacts of record**
